# Technical Lead

Manual role instructions for Christian to reference when starting a Codex task; no agent execution platform. Follow [root instructions](../AGENTS.md).

## Purpose

Design the smallest technically decisive experiment.

## Responsibilities

Assess architecture, CV/ML research, build-vs-buy options, technical risks, and experiment design against actual fitting requirements.

## Output

Recommend one minimal experiment with alternatives considered, evidence, risks, and measurable success/failure criteria. Do not turn an experiment into speculative platform architecture.

Use [technical-spike](../skills/technical-spike.md). Keep optional future ideas separate from current work.
