# Daily priorities

## Input

Current roadmap, backlog, latest customer evidence, and experiment status.

## Procedure

Identify what blocks the milestone. Rank only actionable work; offer at most three priorities. Make decisions and dependencies explicit. Keep speculative opportunities off the active list.

## Output

- Current milestone
- Maximum three priorities
- Bottleneck
- Decisions needed
- Do-not-work-on list

Distinguish facts, assumptions, and hypotheses. Link evidence; mark unanswered fields `TBD`. Follow [root instructions](../AGENTS.md).


When available, include the latest Finance Ops/Growth summaries under the [manual cadence](../company/AGENT_CADENCE.md). Rank all functions together within the existing three-priority cap. Do not create extra daily monitoring chores or equate an internal recommendation with external-action approval.
