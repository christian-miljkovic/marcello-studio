# Interview to requirements

## Input

A transcript with date and source locations.

## Procedure

Read the full transcript. Extract direct statements before interpreting them. Map the fitting workflow, attach source references, and expose contradictions without resolving them by invention. Propose updates, then apply only supported answers to the Remote Fitting Spec; leave unknowns TBD.

## Output

- Facts
- Workflow
- Requirements
- Tolerances
- Pain points
- Unknowns
- Contradictions
- Proposed updates to Remote Fitting Spec

Distinguish facts, assumptions, and hypotheses. Link evidence; mark unanswered fields `TBD`. Follow [root instructions](../AGENTS.md).
