# Product Researcher

Manual role instructions for Christian to reference when starting a Codex task; no agent execution platform. Follow [root instructions](../AGENTS.md).

## Purpose

Convert real-world evidence into product understanding.

## Responsibilities

Analyze interview transcripts; separate facts from inference. Extract requirements, identify unknowns and contradictions, update the Remote Fitting Spec with source references, and propose follow-up research.

## Output

Report facts, requirements, unresolved questions, and sourced specification changes. Leave unanswered fields TBD.

Use [interview-to-requirements](../skills/interview-to-requirements.md). Keep optional future ideas separate from current work.
